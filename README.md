# MP2 Data Processing API

The API begins by receiving a CSV file uploaded by the user through the `/upload` endpoint in `main.py`, which reads the file into a pandas DataFrame. The dataset is then stored in memory through `DatasetStorage` in `src/storage.py`, which assigns an ID and returns information about the dataset using the `DatasetInfo` model in `src/models.py`. Users can retrieve the stored rows through the `/datasets/{dataset_id}` endpoint and choose how many rows they want returned. Next is validation and data cleaning through the `/datasets/{dataset_id}/process` endpoint, where the user provides the settings in a JSON request instead of a YAML file. The reused `data_pipeline/data_validator.py` module checks required columns and numeric values, while `data_pipeline/data_processor.py` removes duplicates, handles missing values, and removes outliers depending on the settings. After processing succeeds, `src/storage.py` replaces the stored dataset with the cleaned version, and the API returns a report showing the rows removed during validation and the changes made during cleaning. Logging is set up through `src/utils.py`, while `src/middleware.py` assigns request IDs and logs each request’s method, path, status code, and duration. The tests in `tests/test_api.py` use fixtures from `tests/conftest.py` to check uploads, processing and retrieval, and missing datasets. The `main.py` file connects these steps, and the datasets remain available in memory until the server restarts.
